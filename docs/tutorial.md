# 教程

> 面向新用户的引导式学习路径。假设你第一次接触这个项目，按顺序阅读。

## 1. 启动仪表盘

### 前提条件

- Python 3.10+
- Node.js 18+
- 包管理器: `pip` + `npm`（或 `bun`）

### 第一步：启动后端

```bash
# 进入后端目录
cd backend

# 安装依赖
pip install -r requirements.txt

# 初始化数据库并填充种子数据
python seed_data.py

# 启动 API 服务器
uvicorn main:app --reload --port 8001
```

后端将在 `http://localhost:8001` 上运行。访问 `http://localhost:8001/docs` 查看 Swagger 交互式 API 文档。

### 第二步：启动前端

```bash
# 进入前端目录（新终端窗口）
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端将在 `http://localhost:5173` 上运行。打开浏览器进入仪表盘。

### 验证启动成功

仪表盘首页应显示：

- 左上角统计卡片: 追踪公司数 / AI 芯片产品数 / 存储产品数 / 产品类别
- 6 家核心公司的实时价格卡片: NVDA、TSM、SK海力士、ASML、AVGO、MU
- 90 日涨跌幅走势折线图
- 市值柱状图 + 产品分类饼图
- 底部 A 股热点榜（需要 akshare 连通）

## 2. 探索产业链全景

"产业链全景"页面是按环节组织的半导体产业链深度分析工具。

**操作步骤：**

1. 左侧导航栏点击 **产业链全景**
2. 页面按 10 个环节展示：原材料 → 设备 → EDA → 芯片设计 → 晶圆制造 → 存储芯片 → 先进封装 → 分销 → 终端市场 → GPU云
3. 每个环节卡片包含：
   - 市场容量预测（2025 / 2026E / 2027E）
   - 供需缺口分析
   - 主要供应商表格（含 PE、市占率、竞争优势）
4. 点击表格中的任意公司 → 展开详情面板：
   - 实时价格 + 90 日走势图
   - 与同环节其他公司的市值比较
   - 市占率比较
   - 历年财务数据表（营收、净利润、毛利率、PE 等）

## 3. 使用产业情报功能

"产业情报"页面是日常监测半导体产业链指标的中心。

**操作步骤：**

1. 左侧导航栏点击 **产业情报**（高亮显示）
2. 页面按环节展示关键指标，每种指标卡片标明层级：
   - **P0 核心**（红色）— 最关键的先行指标
   - **P1 重要**（橙色）— 重要参考
   - **P2 参考**（灰色）— 辅助信息
3. 点击指标卡片的 **关联证券 ±10日** 按钮查看该指标公布前后的相关证券涨跌幅
4. 使用顶部的层级筛选按钮按 P0/P1/P2 过滤
5. 底部有**时间线**，按时间倒序展示所有指标变化和判断记录

**记录判断变化：**

1. 点击 **+ 新增判断** 按钮
2. 填写标题、描述、此前判断、新判断、影响程度等
3. 保存后自动出现在时间线中

---

## 4. 创建投资组合

1. 左侧导航栏点击 **模拟组合**
2. 查看现有组合列表及持仓
3. 系统自动计算组合的累计收益、夏普比率、最大回撤等指标
4. 点击 **评估** 按钮获取 AI 调仓建议

---

## 5. 使用 TSM+EWY 配置方案

"TSM+EWY 配置方案"页面展示了基于 Gordon Growth 模型的估值分析：

1. 左侧导航栏点击 **TSM+EWY配置方案**
2. 查看台积电(TSM)和韩国 iShares MSCI ETF(EWY) 的同群组对比
3. 调整营收增长率、净利率、折现率等参数，点击 **重新计算** 观察估值变化
4. 供需感知未来 PE 计算结果会显示低估/合理估值/高估信号
