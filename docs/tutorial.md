# 教程

> 面向新用户的引导式学习路径。假设你第一次接触这个项目，按顺序阅读。

## 1. 启动仪表盘

### 前提条件

- Python 3.10+
- Node.js 18+
- 包管理器: `pip` + `npm`（或 `bun`）

### 第一步：启动后端

```bash
# 进入后端目录
cd backend

# 安装依赖
pip install -r requirements.txt

# 启动 API 服务器（自动创建数据库 + 运行启动迁移）
uvicorn main:app --reload --port 8001
```

> **注意**: 不再需要手动运行 `seed_data.py`。服务启动时 `main.py` 的 startup 事件会自动：
> 1. 检测并创建数据库
> 2. 运行启动迁移（`startup_migration.py`），补入 SNDK、WDC 等关注公司
> 3. 初始化定时调度器（开始采集）


后端将在 `http://localhost:8001` 上运行。访问 `http://localhost:8001/docs` 查看 Swagger 交互式 API 文档。

### 第二步：启动前端

```bash
# 进入前端目录（新终端窗口）
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端将在 `http://localhost:5173` 上运行。打开浏览器进入仪表盘。

### 第三步（可选）：回填历史价格数据

首次启动后，价格数据需要从外部 API 拉取。运行以下命令补齐 3 年复权价格：

```bash
cd backend
python backfill_3y_prices.py
```

> 该脚本会遍历所有公司，调用腾讯财经 K 线 API（优先）/ yfinance（备选）拉取 1095 天日频数据，写入 `PriceCache` 和 `MarketData` 表。

### 验证启动成功

仪表盘首页应显示：

- 左上角统计卡片: 追踪公司数 / AI 芯片产品数 / 存储产品数 / 产品类别
- 6 家核心公司的实时价格卡片: NVDA、TSM、SK海力士、ASML、AVGO、MU
- 90 日涨跌幅走势折线图
- 市值柱状图 + 产品分类饼图
- 底部 A 股热点榜（需要 akshare 连通）

## 2. 探索产业链全景

"产业链全景"页面是按环节组织的半导体产业链深度分析工具。

**操作步骤：**

1. 左侧导航栏点击 **产业链全景**
2. 页面按 10 个环节展示：原材料 → 设备 → EDA → 芯片设计 → 晶圆制造 → 存储芯片 → 先进封装 → 分销 → 终端市场 → GPU云
3. 每个环节卡片包含：
   - 市场容量预测（2025 / 2026E / 2027E）
   - 供需缺口分析
   - 主要供应商表格（含 PE、市占率、竞争优势）
4. 点击表格中的任意公司 → 展开详情面板：
   - 实时价格 + 90 日走势图
   - 与同环节其他公司的市值比较
   - 市占率比较
   - 历年财务数据表（营收、净利润、毛利率、PE 等）

## 3. 使用产业情报功能

"产业情报"页面是日常监测半导体产业链指标的中心。

**操作步骤：**

1. 左侧导航栏点击 **产业情报**（高亮显示）
2. 页面按环节展示关键指标，每种指标卡片标明层级：
   - **P0 核心**（红色）— 最关键的先行指标
   - **P1 重要**（橙色）— 重要参考
   - **P2 参考**（灰色）— 辅助信息
3. 点击指标卡片的 **关联证券 ±10日** 按钮查看该指标公布前后的相关证券涨跌幅
4. 使用顶部的层级筛选按钮按 P0/P1/P2 过滤
5. 底部有**时间线**，按时间倒序展示所有指标变化和判断记录

**记录判断变化：**

1. 点击 **+ 新增判断** 按钮
2. 填写标题、描述、此前判断、新判断、影响程度等
3. 保存后自动出现在时间线中

## 4. 使用模拟组合

"模拟组合"页面实现了完整的持仓跟踪功能。

**操作步骤：**

1. 左侧导航栏点击 **模拟组合**
2. 页面包含：
   - **核心公司实时价格**横条：当前价 / 涨跌幅 / PE_TTM
   - **组合统计卡片**：总权重、现金权重、加权PE、最新市值
   - **权重配置面板**：每行一个持仓，含 target weight 输入框 + -5%/+5% 按钮
   - **期间收益图表**：90 日归一化走势 + 组合加权线
   - **期间收益表格**：PE_TTM | 1日 | 1周 | 1月 | 3月 | 6月 | 1年 | 3年
   - **EPS/前瞻PE表格**：EPS_TTM | 增速 | 2026E EPS | 2027E EPS | 2026E PE | 2027E PE
3. 系统自动计算组合的累计收益、夏普比率、最大回撤等指标
4. 点击 **评估** 按钮获取 AI 调仓建议

**首次使用**：系统自动播种默认组合 "AI Chip Core Portfolio"（NVDA 30%、GOOGL 20%、TSM 20%、AVGO 15%、AMD 15%）。

## 5. 使用 TSM+EWY 配置方案

"TSM+EWY 配置方案"页面展示了基于 Gordon Growth 模型的估值分析：

1. 左侧导航栏点击 **TSM+EWY配置方案**
2. 查看台积电(TSM)和韩国 iShares MSCI ETF(EWY) 的同群组对比
3. 调整营收增长率、净利率、折现率等参数，点击 **重新计算** 观察估值变化
4. 供需感知未来 PE 计算结果会显示低估/合理估值/高估信号
