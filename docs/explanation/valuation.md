# 估值方法论

本项目实现了两种估值模型：**Gordon Growth 模型（v1）** 和 **供需感知未来 PE 模型（v2）**。两者可互补使用，从不同角度评估半导体公司的合理价值。

---

## v1: Gordon Growth 两阶段 DCF 模型

`backend/valuation.py` 实现了经典的两阶段股息折现变体——用净利润代替股息，计算公司公允价值。

### 核心公式

**第一阶段（高增长 N 年）：逐年计算净利润现值**

```
第 t 年净利润 = 基准营收 × (1 + g)ᵗ × 净利率
第 t 年现值 = 第 t 年净利润 / (1 + r)ᵗ

stage1_pv = Σᵗⁿ₁ 第 t 年现值
```

**第二阶段（永续期）：终端价值折现**

```
第 N 年净利润 = 基准营收 × (1 + g)ᴺ × 净利率
终端价值 = 第 N 年净利润 × (1 + g_term) / (r - g_term)
terminal_pv = 终端价值 / (1 + r)ᴺ

公允价值 = stage1_pv + terminal_pv
公允 PE = 公允价值 / 当前净利润
上涨空间 = (公允价值 / 当前市值) - 1
```

其中：
- `g` = 营收增长率假设
- `r` = 折现率（WACC）
- `g_term` = 永续增长率

### 隐含增长率（Breakeven）

模型使用二分法数值求解：使公允市值等于当前市值的增长率 `g`。这回答了"市场当前价格隐含了多高的增长预期？"

```
范围: -10% ~ 100%，50 次迭代，精度 0.01%
```

### 中国公司国产替代溢价

对于 `is_chinese=True` 的公司，增长率额外加上 `china_premium` 参数（默认 0%），反映国产替代带来的超额增长机会。

### 同群组比较

`compare_peers()` 对同一群组所有公司使用一致参数执行估值，按上涨空间排序，并计算成对 breakeven 矩阵。

### 局限性

1. **不感知供应链周期**：牛市时所有半导体公司看起来都值得投资，熊市时都显得高估
2. **固定增长率假设**：线性增长假设与半导体行业的周期性特征冲突
3. **不区分环节**：设备和设计公司用同一套框架，忽视了差异化的增长驱动因素

## v2: 供需感知未来 PE 模型

`backend/valuation_v2.py` 针对半导体行业的周期性特点设计，将**供应链供需量化分数**直接纳入估值假设。

### 核心思路

> 供需紧张 → 定价权强 → 增长/利润率上调 → 未来PE越低 → 越低估
> 供需宽松 → 定价权弱 → 增长/利润率下调 → 未来PE越高 → 越高估

### 模块 1: SupplyDemandAnalyzer（供需分析器）

从三个维度量化供应链状态，每个维度输出 0-100 分：

| 维度 | 数据输入 | 分数逻辑 | 权重 |
|------|---------|---------|------|
| 供需缺口 | `gap_pct`（负=短缺） | 越负分越高 | 40% |
| 产能利用率 | `capacity_utilization` | >90% 高分，<70% 低分 | 35% |
| 交货周期 | `lead_time_weeks` | >24周=100分，<4周=低分 | 25% |

**综合分 → 定性判断映射：**

| 综合分 | 供应裁决 | 定价权 |
|-------|---------|-------|
| ≥ 75 | 严重短缺 | 强劲定价权 |
| ≥ 55 | 轻度短缺 | 温和定价权 |
| ≥ 35 | 供需平衡 | 定价权中性 |
| < 35 | 供应过剩 | 无定价权 |

**公司级聚合：** 一家公司可能涉及多个产业链环节（如三星=存储+代工）。`aggregate_company_score()` 按各环节收入占比加权聚合，得到公司级供需分数。

### 模块 2: FuturePEModel（未来 PE 估值）

**自动推荐增长率（优先级链）：**

```
分析师一致预期 > 近3年营收CAGR > 所在链市场增长率 > 默认15%
```

**供需对增长率的调整系数：**

| 综合分 | 系数 | 含义 |
|-------|------|------|
| ≥ 75 | ×1.25 | 供给严重短缺 → 高增长可持续 |
| ≥ 55 | ×1.10 | 轻度短缺 → 适度上调 |
| ≥ 35 | ×1.00 | 平衡 → 中性 |
| < 35 | ×0.85 | 过剩 → 下调预期 |

**利润率调整（基于产能利用率近似）：**

| 综合分 | 系数 |
|-------|------|
| ≥ 70 | ×1.10 |
| ≥ 40 | ×1.00 |
| < 40 | ×0.90 |

**未来 PE 计算：**

```
预测净利润 = 当前净利润 × (1 + 调整后增长率)ᴺ
未来PE = 当前市值 / 预测净利润
```

**同群组基准比较：**

```
基准PE = 群组内公司当前PE的中位数
上涨空间 = (基准PE / 未来PE) - 1
估值信号:
  > +20% → 低估
  > 0%   → 合理估值
  > -20% → 略微高估
  ≤ -20% → 高估
```

### 两模型对比总结

| 对比维度 | v1 Gordon Growth | v2 供需感知未来PE |
|---------|-----------------|------------------|
| 理论依据 | 现金流折现 | 相对估值倍数 |
| 供应链感知 | 无 | 供需缺口 → 增长调整 |
| 周期性适应 | 弱 | 强 |
| 参数敏感性 | 折现率、永续增长率 | 供需分数、基准PE |
| 最适合场景 | 稳定增长的半导体巨头 | 周期性波动的产业链环节 |
| 输出形式 | 公允价值+绝对上涨空间 | 低估/合理/高估信号 |
